# Will Awesome Copilot

Banco de customizações para GitHub Copilot: instructions, prompts, skills e agents. O objetivo é reunir orientações e ferramentas reutilizáveis para adaptar o Copilot a diferentes tarefas e fluxos de trabalho.

## Conteúdo

### Instructions

- [README Guidelines](instructions/readme.instructions.md): orientações para criar e manter o README deste repositório.

### Skills

- [Create README Instructions](.github/skills/create-readme-instruction/SKILL.md): cria ou atualiza uma instruction que orienta agentes ao escrever READMEs de projetos.

Prompts e agents também fazem parte do escopo do repositório; seus arquivos poderão ser listados aqui quando forem adicionados.
